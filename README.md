# Les liens de Divine - Wine quiz

Publiés sur `https://go.app-divine.com` par GitHub Pages (dépôt public
`Super-nono/divine-wine-quiz-liens`, copie de ce dossier) :

- `.well-known/apple-app-site-association` : les liens universels de l'app
  (`/i/` invitation, `/d/` défi, `/v/` vin du jour) ;
- `index.html` et `404.html` : la page qui s'ouvre quand l'app n'est pas là.

Pour republier : `outils/liens.sh`.
